# App icon

Generated for this project with the built-in `image_gen` tool. Source artwork:
`app-icon.png`; transparent outside the dark rounded tile. Original image is
retained in the generating session's image library. The art uses no OpenAI logo.

The macOS ICNS and 7-frame Windows ICO are derived by native macOS ImageIO/sips
format and size conversion, using `bash scripts/build-icons.sh`.

## Generation prompt

Create a polished production application icon for a desktop utility called Codex
Quota Reminder. Deliver a single square 1024x1024 icon, no mockup, no surrounding
page, no text, no letters, no numerals. Design: a deep midnight blue-black
rounded-square app tile, with a single bold mint-teal circular reset arrow forming
an almost complete ring, and a small simplified notification bell smoothly
integrated at the lower right of the ring. Clear, distinctive silhouette
recognizable at 16px. Modern macOS/Windows premium utility aesthetic, restrained
soft depth, crisp geometric vector-like edges rendered as a bitmap, subtle tonal
background gradient, excellent contrast. Composition centered with balanced
optical weight, tile occupies around 88% of the canvas. Transparent outside the
rounded tile corners, with no big cast shadow. Palette matches an app UI with
near-black navy background and #4ADBC2 mint-teal highlights. Avoid OpenAI logos,
knots, official brand marks, detailed illustrations, tiny decorative features,
words and lettering. This should feel like quota recovery and a useful alert,
not a finance app.
