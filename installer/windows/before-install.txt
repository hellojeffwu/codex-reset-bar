Codex 额度提醒 · 安装前说明

本程序仅为当前 Windows 用户安装，无需管理员权限。
默认安装位置：%LOCALAPPDATA%\Programs\CodexResetBar

1. 阅读并接受个人使用许可后，按“下一步”选择安装位置。
2. 确认开始菜单文件夹；桌面快捷方式可按需勾选。
3. 点击“安装”，完成后可选择立即运行。

使用前请先在本机安装并登录 Codex CLI。程序不会代装 CLI。
程序自带 .NET 运行时，无需单独安装 .NET。
“登录时启动”由您在应用设置中自行开启，安装时不会自动开启。

升级时，如应用正在运行，安装向导会提示关闭正在使用的安装文件。
若无法自动关闭，请在托盘菜单选择“退出监测”后重试。
请不要将程序安装目录设为用户配置目录。

个人设置、提醒规则与 DPAPI 加密的 Bark Key 保存在：
%LOCALAPPDATA%\CodexResetBar
升级和卸载保留该目录。重新安装后仍可使用原有设置。
